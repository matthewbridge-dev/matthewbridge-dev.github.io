### Project Overview

Leading a 5-engineer capstone engineering team architecting a high-throughput telemetry ingestion pipeline under NDA. The platform receives live sensor streams from ocean monitoring hardware, cleans and parses incoming data frames, and forwards them in real time into an external simulation engine.

### Key Responsibilities

- Architected core system blueprints and data pipelines using UML class and sequence diagrams.
- Implemented functional C++ / ROS2 prototype nodes to validate low-latency data streaming and packet routing.
- Ran sprint standups, delegated tasks, and coordinated code reviews across the team.
