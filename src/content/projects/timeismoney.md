### Project Overview

Built a Goal-Oriented Action Planning (GOAP) simulation in C# and Unity. Rather than relying on rigid finite state machines, NPCs evaluate world states, set strategic goals, and dynamically derive action sequences using A* graph search based on cost and resource availability.

### Key Engineering Features

- Implemented A* search algorithm over dynamic action graphs to resolve multi-step plans in real time.
- Integrated Unity's NavMeshAgent for 3D spatial navigation, obstacle avoidance, and target approach.
- Created visual debugging gizmos to monitor agent goals, current action queues, and internal states during execution.
