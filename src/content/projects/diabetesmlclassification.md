### Project Overview

Developed a binary classification model on clinical patient records to predict diabetes vulnerability. Focused on end-to-end data preparation, addressing data skew, and optimizing decision thresholds to minimize clinical false-negative rates.

### Key Engineering Features

- Implemented data pipelines handling missing values, standard scaling, feature normalization, and class balance adjustments.
- Evaluated multiple Scikit-Learn models using k-fold cross-validation, confusion matrices, and ROC-AUC curve analysis.
- Generated exploratory data visualizations using Pandas, Matplotlib, and Seaborn to identify correlation clusters.
