### Project Overview

Tile Takeover is an interactive tile-matching survival game built in Unity and C#. Players clear rows under pressure to survive as the grid continuously rises toward the ceiling.

### Key Engineering Features

- Designed an event-driven grid management system tracking board state, match detection, and visuals.
- Implemented reactive UI feedback and state machine loops for game-states.
- Engineered reusable C# scriptable objects for tile behaviors, player powers, and modifier effects.
