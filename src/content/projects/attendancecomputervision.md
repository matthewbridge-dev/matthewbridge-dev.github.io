### Project Overview

Developed a facial-recognition attendance tracking application in Python that identifies pre-registered faces in a live camera feed and registers attendance logs without manual intervention.

### Key Engineering Features

- Extracted facial landmarks and 128-d embeddings to compare live feeds against stored biometric datasets.
- Implemented duplicate check thresholds to avoid multiple logs within a single session.
- Exported formatted real-time logs with timestamps, student identifiers, and confidence scores.
